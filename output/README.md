# output/

**测试与日常产出的落地目录。目录保留，内容不入库。**

## 为什么留这个目录

`SaveImage` / `SaveVideo` 的 `filename_prefix` 指到这里，出图后能立刻在仓库里找到，
不用翻 ComfyUI 的 output 深处。但它不该进版本库——一次批量就是几十上百个几 MB 的文件。

## 规则

| 产出性质 | 放哪 |
|---|---|
| 测试、调参、日常随手跑 | **本目录**（被 ignore） |
| 某个项目的正式交付 | **该项目空间**的目录（不在本仓） |
| 需要长期留档的样张 | 项目空间的历史版本或交付批次，按 file-governance |

## 清理

本目录内容可随时清空，不构成资产。清空前确认没有把"还要用的项目产出"放错位置。
